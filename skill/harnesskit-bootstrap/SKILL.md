# Skill 名称

HarnessKit Bootstrap Skill

## 用途

通过 HITL 多轮访谈生成目标项目专属 Harness。

## 适用场景

- 新项目启动
- 既有项目补齐 Harness
- Agent 规则缺失

## 不适用场景

- 直接要求业务代码
- 需要 CLI / 自动化脚本

## 工作流程

1. 项目原点
2. 范围定义
3. 项目事实
4. Agent 规则
5. 功能拆解
6. 验证规则
7. 进度与交接
8. 锁定确认

## 关键规则

- 不写业务代码
- 不编造项目事实
- 未知写 TODO
- 每个功能必须有验收标准与验证方式
- 必须生成 progress 与 session-handoff

## 完成标准

Harness 文件结构完整，可执行，可交接。
