# 工作流总览

HarnessKit 的工作流用于把“模糊需求”变成“可执行 Harness”。

## 执行顺序

1. `01-project-origin-intake`：确认项目原点与问题背景
2. `02-scope-definition`：定义范围与边界
3. `03-project-profile-capture`：捕获项目关键事实
4. `04-agent-rules-generation`：生成 Agent 规则
5. `05-feature-breakdown`：拆解功能与优先级
6. `06-verification-design`：定义验收与验证方式
7. `07-session-handoff`：沉淀交接与下一步
8. `08-harness-lock`：确认 Harness 可执行并锁定

每一轮都应写入对应文件，不跳步、不并轮。
