# 使用指南

## 标准使用路径

1. 将整个 HarnessKit 仓库复制到你的目标项目根目录。
2. 打开 AI 助手，粘贴 `docs/bootstrap-prompt.md` 中的提示词。
3. 按 `workflows/01-08` 执行 HITL 访谈。
4. AI 根据每个文件的职责写入对应内容；未知统一写 `TODO`。
5. 开发前读取关键文档，开发后更新进度、验证与交接。

## 开发前必读

- `AGENTS.md`
- `ai/product-origin.md`
- `ai/scope.md`
- `ai/feature-list.md`

## 开发后必更

- `ai/progress.md`
- `ai/verification.md`
- `ai/session-handoff.md`
